Each case lists the attack and WHERE it is enforced (module builder, main.rs
wiring, or the reused Run 420 verifier/bridge). "unit" = tested in
genesis_consensus_authority.rs #[cfg(test)]; "integ" = run_422 integration test;
"guard" = source-guard test; "reuse" = enforced by pre-existing Run 418/420
verified code exercised via the shared constructor.
