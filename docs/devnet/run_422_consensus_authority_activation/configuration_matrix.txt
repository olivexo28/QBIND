============================================================================
ENV=TestNet / ENV=MainNet (STRICT)
============================================================================

* This task supplies NO real TestNet/MainNet custody material and authorizes NO
  external deployment.
* The flag never downgrades a strict environment: mandatory authority that is
  missing or invalid still rejects (EXIT!=0). map_environment(config.environment)
  is applied when re-hashing, so a wrong-environment genesis fails the canonical
  hash/env policy check.
* LocalFixtureUnsigned remains unreachable through the production CLI (Run 420
  guarantee, re-verified by run_420_production_policy_reachability_tests).

INVARIANTS
============================================================================

* No partially initialized context escapes: the authority is built fully and
  validated BEFORE the bridge constructor runs; any failure exits before P2P.
* No CLI --validator-consensus-key override escapes on the genesis path: it is
  explicitly bypassed (peer_kp_result forced to NoConfiguredKeys).
* Absent activation is byte-identical to Run 421 (NONE + Required).
* Every explicit invalid/partial activation fails nonzero before network start.
