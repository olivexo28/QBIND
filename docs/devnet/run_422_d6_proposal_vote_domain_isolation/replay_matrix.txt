NOTES
----------------------------------------------------------------------------
The domain metadata bytes used above (genesis_identity, authority_commitment)
are FIXTURE values chosen to isolate each boundary. A non-zero fixture hash is
NOT a validated genesis snapshot or an authorized authority snapshot; it proves
only that the field is bound into the preimage, not provenance or freshness
(see compatibility_matrix.txt / D7).

A valid v2 verification result does NOT imply engine acceptance, aggregation,
QC formation, or a committed block. Those boundaries are reported separately and
are not asserted here.
