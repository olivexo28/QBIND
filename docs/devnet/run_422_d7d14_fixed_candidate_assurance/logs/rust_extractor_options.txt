* trap [object]: Options pertaining to TRAP.
* cargo_target_dir [string]: This value is an optional path to use as `CARGO_TARGET_DIR` for the internal cargo commands the extractor uses. Pointing it to a persistent directory may reduce execution time of consecutive extractor runs. By default, a new scratch directory is used for each extraction, while qltests use the test's `target` directory so artifacts can be reused across runs.
* cargo_target [string]: Target architecture to use for analysis, analogous to `cargo --target`. By default the host architecture is used.
* cargo_features [array]: Comma-separated list of features to turn on. By default all features are enabled. If any features are specified, then only those features are enabled. The `default` feature must be explicitly specified if only default features are desired. Can be repeated.
* cargo_cfg_overrides [array]: Comma-separated list of cfg settings to enable, or disable if prefixed with `-`. Can be repeated.
* logging [object]: Options pertaining to logging.
* extract_dependencies_as_source [string]: Extract the full source code of dependencies instead of only extracting signatures.
