Run 416 — dialer process (Laptop 1 WSL, host <dialer-host>)
=======================================================

Publish-safe description of the dialing qbind-node invocation. Exact PIDs, absolute
paths, temp directories, and per-peer key/cert file paths are redacted; the full raw
process listing is retained only in the gitignored bundle
bundles/qbind-m4-evidence-laptop1.tgz.

Invocation shape (publish-safe):

  qbind-node \
    --env devnet \
    --network-mode p2p --enable-p2p \
    --p2p-mutual-auth required \
    --p2p-pqc-root-mode pqc-static-root \
    --p2p-trusted-root <temp-devnet-static-root> \
    --p2p-leaf-cert <temp-leaf.cert.bin> \
    --p2p-leaf-cert-key <temp-leaf.kem.sk.bin> \
    --validator-id 1 \
    --p2p-peer-leaf-cert 0:<redacted-temp-seed-cert-path> \
    --p2p-peer 0@188.166.227.87:30333

Flag notes (moved out of the command so every continuation `\` is the final character
before the newline and the command is syntactically valid):
- `--p2p-trusted-root <temp-devnet-static-root>` — the `devnet_pqc_root_helper` static-root output.
- `--p2p-leaf-cert <temp-leaf.cert.bin>` / `--p2p-leaf-cert-key <temp-leaf.kem.sk.bin>` —
  ephemeral, gitignored; the `0600` KEM secret is NEVER committed.
- `--validator-id 1` — the dialer's validator id.
- `--p2p-peer-leaf-cert 0:<redacted-temp-seed-cert-path>` — the seed's per-peer leaf cert
  (format `VID:PATH`; VID `0` = the seed).
- `--p2p-peer 0@188.166.227.87:30333` — dial the seed (validator id 0).

Notes:
- The per-peer leaf certificate (`--p2p-peer-leaf-cert 0:<...>`, format `VID:PATH`) supplies the
  seed's certified ML-KEM-768 public key so the dialer can complete the mutual-auth static-root
  handshake against the seed's advertised identity (VID 0). The dialer itself runs as
  `--validator-id 1`.
- No certificate bytes, private/KEM secret-key bytes, or absolute operator path are shown; the
  `<redacted-temp-seed-cert-path>` placeholder stands in for the redacted temporary cert path.
- All PQC material is temporary DevNet material from
  crates/qbind-node/examples/devnet_pqc_root_helper.rs and was discarded after the run.
- Angle-bracket <...> placeholders stand in for redacted local paths / values.
