KEY PROPERTIES
  * No configuration path promotes a TIMEOUT context into PV authority. The
    two are nominally distinct types with no conversion or production adapter.
  * PV authority is ABSENT on every production path in this run. It is present
    only via explicit test fixtures.
  * Under Required + PV absent, inbound Proposal/Vote are rejected
    authority-unavailable and outbound Proposal/Vote are suppressed
    (fail closed), independently of whether a valid TIMEOUT context exists.
  * The Timeout/NewView policy (OptionalActivate vs RequireOrFail) is
    preserved exactly; only its former ability to also enable Proposal/Vote
    was removed.
  * Genesis-authority activation remains DISABLED.
