Source anchors in that file:

  421-965: deterministic controls (test names retained in raw output).

inspect(&self) returns classification without creation, replacement,
repair or clearing. Missing, corrupt, truncated, unsupported, foreign,
unreadable and unavailable observations refuse participation. Valid local
records also refuse: no currentness/exclusivity authority exists here.

publish_applying requires matching store/incarnation, claimed writer,
expected revision, supported fixture version and a fixture with no prior
intent attempt or existing observation. It issues IntentAck only for
Acknowledged publication. Failed, Uncertain and VisibleButError return an
error and no token. Visibility is separate from acknowledgement. A failed
attempt cannot simply be replaced by another attempt in the same fixture.
The initial Missing fixture is an explicit test precondition for interface
exercise, NOT a migration, fresh-store initialization or startup procedure.
Modeled restart, including Missing after uncertain publication, cannot
reconstruct permission to initialize or a usable intent token.

IntentAck binds store identity, incarnation, operation, writer and intent
revision. record_outcome also requires the exact current expected revision;
successful publication issues a separate OutcomeAck with the new revision.
Checked revision increment refuses overflow. Failed updates that visibly
publish advance the fake visible revision without issuing acknowledgement.
Scope/revision/ownership failures do not replace existing evidence.

An intent token does not establish an operation barrier. The separate
mutation_gate takes a scripted barrier observation; it is only a fixture
check, not real engine ownership or worker drain. Once an outcome attempt
has progressed, even a failed recording cannot reopen fixture mutation.
No API authorizes signing, startup or participation; no clear/resume API
exists. Complete, no-effect refusal, timeout, late completion and modeled
restart all remain quarantined.

Outcome state retains the completed prefix, all distinct supplied prefix
observations and a sticky prefix-conflict bit. A shorter or different
prefix cannot overwrite the accepted prefix. Each of current-item,
signing, storage-worker, callback and outbound domains has separate known
effect and completion state. Unknown can become resolved; duplicates are
harmless; a different observation after resolved completion, including
Unknown, becomes sticky Conflict. Known effects never reset.
Complete is a retained observation, NOT a clear transition.

Recording first merges valid input into volatile fake observed evidence.
Failure returns RecordFailure with that observed candidate and leaves the
operation unresolved; this is explicitly NOT an acknowledged persistent
record of Unknown. For failed-before-publication and uncertain outcomes,
inspect still returns the prior visible record. VisibleButError can expose
the new record but still returns no acknowledgement. A later successful
retry merges the retained volatile observations, not a fictional recovered
process-crash history. Rejected invalid input remains with the caller;
the interface does not claim it was recorded.

The bounds are synthetic: at most 4 prefix entries per update, 16 evidence
bytes per update, 16 distinct evidence payloads and 16 distinct prefix
observations. Version 1 is a fixture label. Overflow, unsupported version,
or oversized input/aggregate is rejected before store mutation; no
truncation, eviction or fallback serialization occurs.

Fake serialization is sequential &mut access, a one-owner claim and exact
revision comparison inside one object. Store/incarnation labels are
fixture identities, not trusted copy detection or cryptographic tokens.
Different stores/operations/writers/incarnations reject cross-use, including
when the destination has acknowledged its own intent. Copied data with
identical labels cannot be distinguished by a local interface alone.
Separate copies can claim different local writers: no cross-process
fencing, exclusive signer ownership or anti-rollback is demonstrated.
