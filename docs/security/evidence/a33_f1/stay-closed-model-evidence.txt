This is a self-contained Rust integration-test target using std collections
and deterministic fixture state. It imports no consensus engine, node,

flag, crypto setting, operational gate or existing test was modified.

The model has an explicitly named AlreadyRunningFixture precondition for
testing transition into quarantine, not a startup/clear authorization path.
Modeled startup refuses every local observation, including parsed Clean or
Complete. There is no clear operation, currentness authority, cryptographic
mechanism, persistent record schema, recovery procedure or signer-fencing
mechanism. Store and writer IDs are fixture labels, not a persistence format.

The positive control permits only fixture item insertion after acknowledged
intent, closed admission, observed preexisting worker completion and matching
store/writer labels. A barrier or intent failure latches closed. Once a
response terminates, even Complete, acknowledged outcome, empty response or
no-effect refusal remains closed. Intent/outcome publication is intentionally
separate from engine effects and acknowledgement.

Fixture engine state is a small map of IDs and abstract charge units. All
resident entries are treated as protected; capacity refusal and existing-ID
refusal remove/replace nothing. Prefix and observed current-item insertions
remain in the map; Unknown marks unavailable effects, not a proven absence
of effects. This does not implement or test real ancestry eviction, QCs,
vote replay, locks, commits, actual retained-evidence accounting or the
node caller. The earlier real-engine evidence is preserved separately.

Worker fixtures distinguish ordinary admission, cancellation request,
observed completion, outbound enqueue and peer-delivery observation.
Signing-stage fixtures distinguish request, reservation, key invocation and
signature observations from worker completion. These are scripted
observations only: no threads, locks, filesystem, key operations or sockets
are involved. Multiple outstanding workers retain Unknown until each
required completion is observed. Late completion does not reopen admission.

Local mock writer serialization refuses a competing writer in either
deterministic claim order; changed owner/store and foreign-store fixtures
invalidate admission. A separate control deliberately demonstrates that
two copied stores can each acknowledge their own local writer. Neither copy
can authorize participation from its parsed record. This models the limit
of local ownership, not actual concurrency or cross-copy signer fencing.
