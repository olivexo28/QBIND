# QBIND

QBIND is an experimental post-quantum blockchain node.

## Public DevNet (experimental — NOT launch-ready)

Public DevNet is **experimental, resettable, and NOT launch-ready**. It carries no value and makes no
MainNet or TestNet readiness claim. Published, operator-verifiable public DevNet artifacts live under
`docs/release/public-devnet/`:

- **Genesis package:** `docs/release/public-devnet/genesis/`
- **Seed-list format + placeholder:** `docs/release/public-devnet/network/`
- **External operator onboarding (build, verify, run, identity, safety):**
  `docs/release/public-devnet/operator/` — start with
  [`operator/QUICKSTART.md`](docs/release/public-devnet/operator/QUICKSTART.md).

Public DevNet readiness is tracked in
`docs/release/QBIND_PUBLIC_DEVNET_READINESS_CRITERIA.md`.
